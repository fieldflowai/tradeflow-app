# WorkCraft AI logo files

The logo system uses a continuous W-shaped route that moves forward into an arrow, representing WorkCraft AI and the idea of keeping work moving. It is drawn in the same sage and orange palette with the WorkCraft AI wordmark. The two tagline lines are:

- For the people who get the work done.
- Keep good work moving.

## Files

- `workcraft-ai-logo.png` — transparent horizontal logo, 1520 × 360 px; use on light backgrounds.
- `workcraft-ai-logo-reversed.png` — transparent horizontal logo, 1520 × 360 px; use on dark backgrounds.
- `workcraft-ai-profile.png` — square 1024 × 1024 px profile/avatar icon.
- `workcraft-ai-linkedin-banner.png` — horizontal 1584 × 396 px banner, composed for a LinkedIn background image.
- `workcraft-ai-linkedin-profile-banner.png` — 1584 × 396 px version with the mark and message shifted away from the overlapping profile photo.
- `workcraft-ai-facebook-cover.png` — horizontal 1640 × 624 px cover image, composed for Facebook.
- Matching SVG files are provided for crisp scaling and editing.

The banner artwork keeps the brand and message in the central safe area so it stays readable when a service crops the edges. Upload the PNG for social profiles; keep the SVG as the editable master.

The app and marketing site use the shared mark from their public asset folders. Use the PNG files for services that do not accept SVG uploads.

The standalone profile mark is an icon-first option when a service crops uploaded profile images to a circle. For profiles that allow a landscape logo, use one of the horizontal exports so the brand name remains visible.
