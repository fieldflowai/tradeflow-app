# WorkCraft AI logo files

The logo system uses one sage and orange mark with the WorkCraft AI wordmark. The two tagline lines are:

- For the people who get the work done.
- Keep good work moving.

## Files

- `workcraft-ai-logo.png` — transparent horizontal logo, 1520 × 360 px; use on light backgrounds.
- `workcraft-ai-logo-reversed.png` — transparent horizontal logo, 1520 × 360 px; use on dark backgrounds.
- `workcraft-ai-profile.png` — square 1024 × 1024 px profile/avatar icon.
- Matching SVG files are provided for crisp scaling and editing.

The app and marketing site use the shared mark from their public asset folders. Use the PNG files for services that do not accept SVG uploads.

The standalone profile mark is an icon-first option when a service crops uploaded profile images to a circle. For profiles that allow a landscape logo, use one of the horizontal exports so the brand name remains visible.
